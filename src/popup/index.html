NOLEAKER FLOW

Google Flow unlock

Firefox has not given this extension access to the Flow pages, so the unlock cannot run.

On flow.google.com and labs.google/fx/tools/flow only, it rewrites the country check in Flow's own answers and sends the tab back to Flow if it lands on the "unsupported country" page. It does not route traffic: use a proxy (for example noleaker) for that. Open Flow tabs need a reload after you change the switch.
